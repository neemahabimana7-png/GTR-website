# Learn Django using your Grittech website

Start with the backend README to run the project. Study lessons 01 through 11 in filename order. You can read a lesson without changing code; exercises use a local test database or an isolated learning branch, never real production data.

1. Django introduction: browser, server and MVT.
2. Project structure: how this backend is organized.
3. URLs and views: following a page request.
4. Templates and static files: your frontend copies.
5. Models and database: the Inquiry record.
6. Forms and validation: the Contact page.
7. Admin: staff access and permissions.
8. Email: console versus actual SMTP.
9. Security: protections and their limits.
10. Tests and debugging: evidence, not guesses.
11. Deployment: what must change before public launch.

Use [CODE-WALKTHROUGH](CODE-WALKTHROUGH.md) when opening a Python file, [DJANGO-COMMANDS](DJANGO-COMMANDS.md) while working in the terminal, and [IMPLEMENTATION-JOURNAL](IMPLEMENTATION-JOURNAL.md) to follow the actual implementation sequence. Operational guides in the parent docs directory are cross-referenced rather than repeated in every lesson.
